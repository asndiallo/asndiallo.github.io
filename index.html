Latest Project (In Progress)

YoBool

YoBool is a community-driven application designed to facilitate the booking of excess baggage space and the posting of travel ads. Emphasizing eco-responsibility and security, YoBool connects travelers looking to optimize their luggage space. As the backend developer, I utilized Ruby on Rails in API-only mode to ensure a scalable and secure architecture, employing PostgreSQL for database management, Redis for caching and docker for deployment. The frontend is developed using React. This project highlights my expertise in backend development, API integration, and collaboration on full-stack applications. here.
